# Analyse de Valorisation — Ryanair

> Modèle financier intégré 5 ans · Valorisation DCF & EV/EBITDA · Mémo d'investissement  
> Projet académique — INSEEC Grande École · 2025–2026

---

## Objectif

Construire une analyse financière complète de Ryanair permettant de formuler une recommandation d'investissement structurée (buy / hold / sell), sur le modèle d'une note d'analyste.

---

## Méthodologie

### 1. Modèle financier intégré 5 ans
- Compte de résultat, bilan et tableau de flux de trésorerie consolidés et liés
- Analyse des drivers de rentabilité : marges opérationnelles, coût unitaire par passager, sensibilité carburant
- Projections ancrées sur les tendances historiques et les guidances de la direction

### 2. Valorisation
- **DCF** : modèle explicite 5 ans + valeur terminale ; analyse de sensibilité sur le WACC et le taux de croissance terminal
- **Multiples EV/EBITDA** : sélection d'un panel de comparables cotés, calcul des fourchettes implicites de valeur

### 3. Benchmarking concurrentiel
- Analyse comparée Ryanair / easyJet / Wizz Air sur les KPIs opérationnels et financiers clés
- Positionnement dans la dynamique de consolidation du secteur low-cost européen

### 4. Mémo de recommandation
- Synthèse dans un format mémo d'investissement (buy / hold / sell)
- Présentation et défense devant un jury académique
